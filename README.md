<h1>Persona - a Quake 4 Mod (in progress)</h1>

**How to Install:**
1. git clone the repository into your local files
2. Open up the q4sdk.sln
3. Change release configuration from Debug to Release
4. Build idLib project, fix 2 of the errors, and hit build again
5. After building Game go to the folder where you cloned the repository -> Win32 -> Release -> copy the Gamex86.dll file
6. Create a mods folder where your Quake 4 game is stored in your local files.
7. There's a folder called Q4base which contains pk files
8. Copy game000.pk4 file into your mods folder
9. Open archive w/ 7zip and delete dll file
10. Copy new dll from Release folder and paste it into pk4 file


**Synopsis:**
- Defeat enemies to gain experience points and level up to become unstoppable.

**Level Ups:**
- Level 2: Infinite Armor Recovery
- Level 4: Infinite Health Recovery
- Level 6: Invisibility for 60 Seconds
- Level 8: Quad Damage for 40 Seconds
- Level 10: Haste for 60 Seconds
